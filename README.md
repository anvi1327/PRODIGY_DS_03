# PRODIGY_DS_03
Bank Marketing data analysis


Task Overview
This project focuses on data cleaning, preprocessing, and exploratory data analysis (EDA)
of a bank marketing dataset to understand customer behavior and factors influencing
whether a customer subscribes to a term deposit.

Dataset Description
The dataset contains customer demographic, financial, and campaign-related information
such as age, job, marital status, housing loan, personal loan, and campaign outcome.

Dataset Source
Kaggle: Bank Marketing Dataset

Target Variable:
- `default` / `y` (indicates whether the customer subscribed or not)

Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

Steps Performed
- Loaded the dataset using Pandas
- Inspected data structure, data types, and missing values
- Removed irrelevant columns
- Converted categorical variables into numerical format
- Performed exploratory data analysis using count plots
- Analyzed correlations between variables using a heatmap
- Prepared data for machine learning modeling

Exploratory Data Analysis
- Analyzed subscription rates based on housing and loan status
- Compared customer behavior across different job and marital categories
- Used correlation heatmap to identify relationships between numerical variables

 Outcome
The analysis helps identify key factors affecting customer subscription decisions
and prepares the dataset for predictive modeling using classification algorithms.
